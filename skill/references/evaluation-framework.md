# 智择通评分体系完整框架

## 一、综合评分公式

```
综合分 = S×0.25 + P×0.25 + M×0.25 + R×0.15 + T×0.10
```

---

## 二、学校综合评分（S）

```
S = 排名分×0.30 + 资源分×0.25 + 地域分×0.20 + 就业分×0.25
```

### 排名分（×0.30）
- QS/Times/US News综合排名
- 专业排名（目标专业）
- 排名趋势（近5年变化）

### 资源分（×0.25）
- 校友资源指数（知名校友数量+质量）
- 导师资源指数（五层数据模型评估）
- 学术资源（论文/专利/项目）

### 地域分（×0.20）
- 城市经济活力
- 行业聚集程度
- 生活成本（房价/物价）

### 就业分（×0.25）
- 就业率（毕业6个月内）
- 平均起薪
- 知名企业校招频次
- 行业分布多样性

---

## 三、专业前景评分（P）

```
P = 行业趋势×0.40 + 就业率×0.30 + 薪资水平×0.30
```

### 行业趋势评估
- 当前行业处于康波周期哪个阶段
- 4-7年后行业预判
- 政策支持力度

### 就业率评估
- 该专业全国平均就业率
- 目标学校该专业就业率
- 就业质量（专业对口率）

### 薪资水平评估
- 毕业起薪（0-3年）
- 职业中期薪资（5-10年）
- 薪资增长曲线

---

## 四、导师价值评分（M）

```
M = 学术×0.25 + 人脉×0.25 + 行业×0.25 + 产出×0.15 + 资源×0.10
```

### 导师五层数据模型

| 层级 | 数据类型 | 自动化程度 |
|-----|---------|-----------|
| Layer 1: 基础层 | 姓名、职称、研究方向、论文列表、H指数 | 80% |
| Layer 2: 项目层 | 国家自然科学基金项目、经费规模 | 70% |
| Layer 3: 企业层 | 董事/顾问任职、专利许可 | 70% |
| Layer 4: 人脉层 | 师承关系、同门网络、学术圈地位 | 50% |
| Layer 5: 产出层 | 学生去向、就业企业、创业情况 | 30% |

---

## 五、资源匹配评分（R）

```
R = 学校资源×0.40 + 家长资源×0.60
```

### 家长资源评估维度

#### 家庭资源指数（FRI）
```
FRI = 经济资源×0.35 + 社会资源×0.35 + 认知资源×0.30
```

**经济资源（×0.35）**
- 学生家庭年收入分布
- 多城市房产家庭比例
- 海外留学/移民家庭比例
- 创业家庭/企业主家庭比例

**社会资源（×0.35）**
- 家长职业分布（公务员/企业高管/专业人士占比）
- 家长职位层级（司局级/处级/科级占比）
- 家长社会地位
- 家长人脉网络覆盖度

**认知资源（×0.30）**（最难量化但最重要）
- 家长学历层次（硕博占比）
- 家长教育投入意愿
- 教育理念一致性
- 长期规划意识

#### FRI学校分级
| 等级 | 分数 | 代表学校 |
|-----|------|---------|
| S级 | 90-100 | 哈佛/耶鲁/清北复交 |
| A级 | 80-89 | 常春藤/985强校/上财/北外 |
| B级 | 70-79 | 211院校/省重点大学 |
| C级 | 60-69 | 普通一本/二本院校 |
| D级 | <60 | 专科/高职院校 |

---

## 六、时机评分（T）

```
T = 康波周期×0.50 + 行业周期×0.30 + 入学时机×0.20
```

### 康波周期阶段判定
- 上升期：技术创新扩散，新产业崛起（10-15年）
- 繁荣期：高速增长，泡沫化（10-15年）
- 衰退期：增速放缓，结构调整（5-10年）
- 萧条期：深度调整，出清（5-10年）

### 入学时机评估
- 当前出生人口趋势（竞争密度）
- 目标省份考生数量变化
- 目标专业招生计划变化
