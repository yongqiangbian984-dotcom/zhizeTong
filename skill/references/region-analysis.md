```

```

## 六、地域选择三大策略

### 策略一：本地化策略
- **目标**：留乡/回老家发展
- **策略**：选本地学校性价比最高
- **核心**：本地学校在本地的认可度不低于外地名校，本地人脉可直接复用
- **适用**：三四线城市、父母有本地资源

### 策略二：目标城市策略
- **目标**：去一线城市发展
- **策略**：必须考目标城市的学校
- **核心**：北京就业极度看本地学历（清北人航），上海看复旦交大，深圳看本地+广州
- **适用**：非本地户籍、想去大城市

### 策略三：留学移民策略
- **目标**：海外工作/移民
- **策略**：学校排名比地域更重要
- **核心**：哈佛/斯坦福/MIT全球认可，移民政策：技术移民/留学移民/投资移民
- **适用**：高净值家庭、想移民、全球化发展
