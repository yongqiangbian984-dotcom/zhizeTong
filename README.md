# 智择通 🎓

> 中国首个基于 AI Agent + 康波周期理论的智能择校决策平台

**择校不只是选学校，是选「知识+资源+时机」**

## 🌟 核心理念

传统择校只看排名和分数线，但这忽略了一个关键事实：**你选的不只是学校，选的是4-7年后的行业入场券、是地域的时间价值、是人脉资源的起点。**

智择通从5个维度帮你做出最优决策：

| 维度 | 权重 | 核心价值 |
|------|------|---------|
| **S 学校综合分** | 25% | 排名+资源+地域+就业，不只看排名 |
| **P 专业前景分** | 25% | 结合康波周期预判4-7年后行业走势 |
| **M 导师价值分** | 25% | 五层数据模型评估导师真实价值 |
| **R 资源匹配分** | 15% | 家庭资源指数FRI匹配学校圈层 |
| **T 时机分** | 10% | 康波周期+出生人口趋势判断入场时机 |

## 🔥 三大独家视角

### 1. 康波周期择校

基于50-60年康波周期理论，预判4-7年后行业趋势：

| 行业 | 当前周期 | 4-7年后 | 推荐 |
|------|---------|---------|------|
| AI/大数据/芯片 | 📈 上升期 | 繁荣期 | ⭐⭐⭐⭐⭐ |
| 新能源/储能 | 📈 上升期 | 繁荣期 | ⭐⭐⭐⭐⭐ |
| 生物医药 | 📈 上升期 | 繁荣期 | ⭐⭐⭐⭐ |
| 互联网/金融科技 | ➡️ 繁荣期 | 稳定期 | ⭐⭐⭐ |
| 房地产 | 📉 衰退期 | 萧条期 | ⭐ |

### 2. 地域价值差

同样程序员，不同城市年收入天差地别：
- 包头：8-15万 | 深圳：30-60万 | 硅谷：80-200万

**时间价值 = (收入 + 社会福利 + 隐性福利) - 生活成本 - 竞争成本**

选学校=选城市=选4年后的起跑线

### 3. 反向溯源

不说「我有什么分能上什么学校」，而是「我想成为谁，需要进什么学校」。

从目标人物/企业/行业倒推学校-导师-资源链路。

## 💡 核心创新点

1. **五维评分模型** — 超越单一排名，综合评估学校/专业/导师/资源/时机
2. **康波周期择校** — 用50-60年经济周期理论预判行业趋势
3. **地域价值差分析** — 量化不同城市的时间价值回报
4. **家庭资源指数（FRI）** — 衡量学校圈层的家庭背景质量
5. **反向溯源** — 从目标人物倒推学校-导师-资源链路
6. **深度画像** — 3个月持续对话替代一次性测评
